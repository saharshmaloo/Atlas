# Evaluation corpus

`retrieval-v1.json` is a synthetic, versioned corpus with manually specified source relevance. Run `TEST_DATABASE_URL=... python -m pytest tests/test_evaluation.py -q -W error` against PostgreSQL 17. Each test builds a disposable database, ingests the exact texts, generates passages, and searches the labeled queries at k=5.

Keyword baseline: recall@5 = 0.8, MRR@5 = 0.8, nDCG@5 = 0.8; empty-query accuracy = 1.0. The intentionally missed synonym case exposes a keyword limitation. This tiny fixture checks regressions; it does not establish general research quality. Source-level relevance works here because every fixture has one passage. Expand labels at passage level for larger corpora. No production data or paid calls are used.

`grounding-v1.json` labels supported, contradicted, unresolved, and insufficient-evidence cases. The fixture answer provider deliberately emits both correct and incorrect claims with valid citations. With the default unconfigured semantic verifier, citation membership is 1.0, support-label accuracy is 1/3 (all judgments uncertain), and abstention accuracy is 1.0. False-support rate is undefined because no claims are classified supported. These are contract baselines with synthetic provider output, not live model quality results. Changing retrieval or verification requires rerunning both corpora and reporting these metrics separately.

`memory-v1.json` repeats three labeled tasks with/without supported retained findings. Run `TEST_DATABASE_URL=... python -m pytest tests/test_memory_evaluation.py -q -s -W error` for a JSON report. With the fixed fake answer/verifier, fixture quality accuracy changes from 2/3 to 1.0; keyword retrieval calls remain 3 in both arms, and answer-provider calls increase from 1 to 2 because a previously unanswered synonym question becomes answerable. One local run measured 3ms versus 9ms generation time and 465 versus 929 provider-input characters. Latency varies by machine. Paid cost is zero for these fakes; call/input sizes are cost proxies, not real model prices. This checks evidence reuse and the evaluation procedure, not live model quality or a demonstrated cost/latency improvement. Memory expansion remains opt-in.
